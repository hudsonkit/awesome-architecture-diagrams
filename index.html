Diagrams as code

Author diagrams in text or a programming language, then render them for documentation or review.

  • ARC

    Typed TypeScript and JSON architecture diagrams with a React renderer, visual editor, and CLI; a companion viewer provides lossy Mermaid flowchart and state-diagram import.

    github.com

  • Archify

    Agent skill that turns descriptions or repository analysis into typed JSON source and self-contained interactive HTML diagrams.

    github.com

  • C4-PlantUML

    PlantUML macros for authoring C4 diagrams; requires PlantUML rather than providing a standalone modeling application.

    github.com

  • D2

    Declarative diagram language with nested containers, multiple layout engines, and a local CLI.

    d2lang.com

  • Diagrams

    Python library for cloud and on-premises architecture diagrams using provider node types and Graphviz rendering.

    diagrams.mingrammer.com

  • Graphviz

    Graph visualization tools that lay out and render DOT descriptions of nodes, edges, and clusters.

    graphviz.org

  • Mermaid

    Text-based diagramming library for flowcharts, sequence diagrams, and other diagram types embedded in documentation.

    mermaid.ai

  • PlantUML

    Text-based UML and related diagrams, including component, deployment, and sequence diagrams.

    plantuml.com

Architecture models and views

Describe architecture concepts and relationships, or use a defined notation to communicate them across diagrams.

  • Archi

    Desktop modeling application for ArchiMate enterprise architecture models and views.

    archimatetool.com

  • IcePanel

    Visual C4 modeling tool that reuses model objects across connected architecture diagrams.

    icepanel.io

  • Ilograph

    Model-based, interactive system diagrams with automatic layouts and zoomable views of components and flows.

    ilograph.com

  • LikeC4

    Architecture DSL that generates interactive views from a shared model and supports embedding diagrams in applications and documentation.

    likec4.dev

  • Structurizr

    C4 models as code using Structurizr DSL to create multiple architecture views from one model.

    docs.structurizr.com

Visual editors

Draw and arrange diagrams directly. General-purpose editors are included when they support software architecture sketching or documentation.

  • draw.io

    Visual diagram editor, also available at app.diagrams.net, with UML, network, and infrastructure shape libraries.

    drawio.com

  • Eraser

    Technical diagramming workspace with a visual canvas, diagram-as-code authoring, and AI-assisted diagram generation.

    docs.eraser.io

  • Excalidraw

    Open-source whiteboard with a hand-drawn style for sketching systems and collaborating on early designs.

    github.com

Rendering services

Convert existing diagram source into images through an API; the source language still defines the diagram.

  • Kroki

    Unified HTTP rendering API for languages and tools including Graphviz, Mermaid, PlantUML, and D2.

    kroki.io

Diagram UI and layout libraries

Building blocks for custom editors and viewers. These require application development.

  • ELK.js

    JavaScript graph layout algorithms that compute element positions and edge routes. Rendering and interaction are supplied by the consuming application.

    github.com

  • React Flow

    React components for interactive node-and-edge editors and viewers, with customizable nodes and edges; applications supply layout separately.

    reactflow.dev

Learning resources

Methods and notation for communicating software architecture across levels of detail.

  • C4 model

    A framework for describing software architecture through system context, container, component, and code diagrams.

    c4model.com
